# Практическая работа 11

Каждый task_N.cpp — самостоятельная программа на C++17. Компилируйте один файл за раз.

## Задание 1. Маршрут с максимальной суммой

Файл: `task_1.cpp`.

Ввод: N M, затем N строк по M целых чисел.

Динамическое программирование с восстановлением пути. Движение только вниз и вправо, индексы с нуля. Выводится сам маршрут без суммы. При равных суммах выбирается предыдущая клетка сверху. Суммы должны помещаться в long long.

Пример входных данных:
```text
3 4
2 -3 2 3
10 2 2 2
-3 20 2 2
```

Результат:
```text
0 0
1 0
1 1
2 1
2 2
2 3
```

## Задание 2. Распределение пирожков

Файл: `task_2.cpp`.

Ввод: N D (1 <= D <= N <= 1000), затем N целых калорийностей в диапазоне int.

Неоднозначность: минимизируем максимальную разницу max-min среди D непустых дней. Все пирожки используются, исходный порядок не обязателен. Сортировка и двоичный поиск по ответу; проверка жадным разбиением. Это минимаксная трактовка, так как буквальный минимум по одному из дней часто равен нулю.

Пример входных данных:
```text
5 2
1 2 3 10 11
```

Результат:
```text
2
```

## Задание 3. Букет

Файл: `task_3.cpp`.

Ввод: N K L, затем N целых стоимостей (1 <= N <= 100, 1 <= L <= K <= 20).

В условии не заданы типы и количество экземпляров. Принято: N — число видов, каждого вида доступно до L экземпляров. Каждый элемент массива — отдельный вид, даже при равных стоимостях. Выбираем ровно K растений динамическим программированием. Если N * L < K, выводим Impossible. Для N отдельных доступных экземпляров потребуется уточнить виды; эта версия решает описанную здесь трактовку. Стоимости и итог должны помещаться в long long.

Пример входных данных:
```text
3 4 2
10 7 3
```

Результат:
```text
34
```
