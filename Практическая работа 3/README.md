# Практическая работа 3

Каждый файл — отдельная программа на C++17 со своей функцией `main`. Объединять файлы в одну программу не нужно.

## Задание 1. Гипотенуза

Файл: `task_1.cpp`.

Ввод: Два положительных катета a и b.

Теорема Пифагора.

Пример ввода:
```text
3 4
```

Пример результата:
```text
5
```

## Задание 2. МКАД

Файл: `task_2.cpp`.

Ввод: Целая скорость v и неотрицательное время t в часах.

Двойной остаток корректно учитывает отрицательную скорость. Произведение v * t должно помещаться в long long.

Пример ввода:
```text
-1 1
```

Пример результата:
```text
108
```

## Задание 3. Число десятков

Файл: `task_3.cpp`.

Ввод: Неотрицательное целое n.

Деление на 10 и остаток от деления на 10.

Пример ввода:
```text
123
```

Пример результата:
```text
2
```

## Задание 4. Следующее чётное

Файл: `task_4.cpp`.

Ввод: Целое n, для которого ответ помещается в long long.

Арифметическая формула без if и циклов, в том числе для отрицательных чисел.

Пример ввода:
```text
-3
```

Пример результата:
```text
-2
```

## Задание 5. Электронные часы

Файл: `task_5.cpp`.

Ввод: Неотрицательное количество секунд с начала суток.

Часы сбрасываются после 24 часов; минуты и секунды выводятся двумя цифрами.

Пример ввода:
```text
3661
```

Пример результата:
```text
1:01:01
```

## Задание 6. Обмен переменных

Файл: `task_6.cpp`.

Ввод: Два целых числа a и b.

Без дополнительной переменной. Сумма a + b должна помещаться в long long.

Пример ввода:
```text
12 -5
```

Пример результата:
```text
-5 12
```

## Задание 7. Улитка

Файл: `task_7.cpp`.

Ввод: Положительные целые h, a, b: высота, подъём за день, спуск за ночь.

После достижения вершины улитка уже не спускается. Если вершина недостижима, выводится Impossible.

Пример ввода:
```text
10 3 2
```

Пример результата:
```text
8
```

## Задание 8. Симметричное число

Файл: `task_8.cpp`.

Ввод: Число от 0 до 9999.

Сравнение пар цифр без if и циклов. Недостающие старшие разряды считаются нулями. Ответ 1 или 0.

Пример ввода:
```text
1221
```

Пример результата:
```text
1
```

## Задание 9. Делимость

Файл: `task_9.cpp`.

Ввод: Два натуральных числа n и m.

Логическое выражение без if и циклов. Ответ 1 или 0.

Пример ввода:
```text
12 3
```

Пример результата:
```text
1
```

## Задание 10. Максимум без ветвлений

Файл: `task_10.cpp`.

Ввод: Два целых числа от 1 до 1000.

Только целочисленные арифметические операции и присваивание; без max, abs, сравнений, условий и циклов.

Пример ввода:
```text
20 7
```

Пример результата:
```text
20
```

Раздел про указатели содержит разбор примеров, но отдельного условия задачи в нём нет. Здесь решены все 10 явно сформулированных задач на ввод-вывод.
