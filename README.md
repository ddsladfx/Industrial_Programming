## Запуск

Откройте нужный `.cpp` в Visual Studio или другой среде с поддержкой C++17, соберите и запустите. Файлы сохранены в UTF-8.

Из командной строки с GCC:

```sh
g++ -std=c++17 "Практическая работа 1/task_1.cpp" -o task
```

Запуск: `./task` в Linux/macOS или `.\task.exe` в PowerShell. В терминале разработчика Visual Studio:

```bat
cl /EHsc /std:c++17 /utf-8 "Практическая работа 1\task_1.cpp" /Fe:task.exe
task.exe
```

Кроме интерактивного угадывания числа, программы читают данные без приглашений и выводят результат. Обычно предполагается корректный ввод в диапазоне из README. Исполняемые файлы в репозитории не хранятся.

## Особенности условий

Вторая работа в исходной методичке посвящена Scratch: здесь это консольная адаптация на C++, без спрайтов и звуков. Исходный Scratch-проект сохранён в папке `Архив`.

В некоторых условиях не заданы диапазоны или есть неоднозначности. Принятые трактовки указаны рядом с заданиями: границы целочисленных типов, римские числа от 1 до 3999, вещественное деление, объём за текущий день и уход соседних групп студентов.

Упоминания дополнительной и контрольной работ без конкретных условий не включены в решения.

## Проверка

Все 40 программ собраны компилятором MSVC в режиме C++17 с `/W4` без предупреждений.

Для работ №1–6 пройдено 1996 автоматических проверок: примеры и граничные случаи, все 1023 числа для угадывания, сравнение количества команд с полным поиском для малых A и B, последовательность «посмотри и скажи» до 25-го элемента для нескольких начальных значений.

Для добавленных работ №8, 9, 11, 12 и 14 пройдено ещё 195 проверок: текстовые файлы, русские слова в UTF-8, корректность перекладывания ингредиентов, маршруты, полный перебор небольших распределений пирожков и букетов, независимый поиск по состояниям лабиринта. Отдельная проверка стека содержит 1500 команд.
