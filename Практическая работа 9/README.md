# Практическая работа 9

Каждый task_N.cpp — самостоятельная программа на C++17. Компилируйте один файл за раз.

Имена входных и выходных файлов заданы условиями. Создавайте их в текущей рабочей папке запущенной программы. Программы 1 и 3 перезаписывают output.txt.

## Задание 1. Удаление букв

Файл: `task_1.cpp`.

Ввод: Содержимое input.txt, до 10000 английских символов.

Результат записывается в output.txt. Удаляются буквы из user agreement без учёта регистра, пробелы и переводы строк сохраняются.

Пример входных данных:
```text
useragreement45kkl
```

Результат:
```text
45kkl
```

## Задание 2. Поиск подстроки

Файл: `task_2.cpp`.

Ввод: Строка X в input1.txt, строка Y в input2.txt; до 10000 маленьких латинских букв.

Результат выводится в консоль. Проверяем Y внутри X по первому абзацу условия; последняя фраза документа задаёт обратное направление и противоречит ему. Пустая строка считается подстрокой.

Пример входных данных:
```text
input1.txt: abcdef
input2.txt: bcd
```

Результат:
```text
yes
```

## Задание 3. Числа в двоичную систему

Файл: `task_3.cpp`.

Ввод: Одна строка в input.txt длиной до 255 символов; в числах нет ведущих нулей.

Результат в output.txt. Каждая непрерывная группа цифр — отдельное десятичное число. Деление десятичной строки столбиком позволяет обработать даже число из 255 цифр без переполнения.

Пример входных данных:
```text
6^&678JKjdkdl;?.,lk879Pk1kdfl4839
```

Результат:
```text
110^&1010100110JKjdkdl;?.,lk1101101111Pk1kdfl1001011100111
```
