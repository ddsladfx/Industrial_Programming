# Практическая работа 5

Каждый файл — отдельная программа на C++17 со своей функцией `main`. Объединять файлы в одну программу не нужно.

## Задание 1. Рост суммы по дням

Файл: `task_1.cpp`.

Ввод: Положительные действительные X и Y.

Каждый день объём увеличивается на 10%. Сравнивается объём за текущий день с Y, а не накопленная сумма. Использовано >= из требования к выводу; в описании также встречается формулировка «более Y».

Пример ввода:
```text
100
121
```

Пример результата:
```text
3
```

## Задание 2. Минимум команд

Файл: `task_2.cpp`.

Ввод: Натуральные A и B, A > B.

Делим чётное число пополам, если результат не меньше B. Иначе вычитаем 1. Последняя оговорка нужна для достижимости B; буквальное требование делить любое чётное число противоречит условию для, например, A = 10, B = 6.

Пример ввода:
```text
10 1
```

Пример результата:
```text
:2
-1
:2
:2
```

## Задание 3. Студенты

Файл: `task_3.cpp`.

Ввод: N от 0 до 1000, затем N чисел от 0 до 9.

На каждом проходе уходят все соседние группы длиной не меньше двух, затем оставшиеся сдвигаются. Повторяем до остановки. В условии не уточнены группы нечётной длины и порядок ухода: здесь группа 1 1 1 уходит целиком, а все группы одного прохода уходят одновременно.

Пример ввода:
```text
6
1 2 3 3 2 1
```

Пример результата:
```text
6
```
