# Практическая работа 6

Каждый файл — отдельная программа на C++17 со своей функцией `main`. Объединять файлы в одну программу не нужно.

## Задание 1. Побочная диагональ

Файл: `task_1.cpp`.

Ввод: N от 1 до 100.

Положение клетки определяем по сумме индексов i + j.

Пример ввода:
```text
4
```

Пример результата:
```text
0 0 0 1
0 0 1 2
0 1 2 2
1 2 2 2
```

## Задание 2. Карта грибов

Файл: `task_2.cpp`.

Ввод: N M (1–32), затем W (0–1000), затем W пар координат строка столбец. Координаты начинаются с 1.

Считаются восемь соседей. Повтор координаты обозначает ту же занятую клетку. Символы выводятся без пробелов, как прямо требует условие, хотя в примере документа пробелы есть.

Пример ввода:
```text
3 2
2
1 1
2 2
```

Пример результата:
```text
*2
2*
11
```

## Задание 3. Посмотри и скажи

Файл: `task_3.cpp`.

Ввод: X от 0 до 100 и N от 1 до 25.

Одинаковые соседние цифры заменяем их количеством и самой цифрой. X — строка из цифр, поэтому при X = 100 обрабатываются все цифры, а не один символ.

Пример ввода:
```text
1 4
```

Пример результата:
```text
1211
```
