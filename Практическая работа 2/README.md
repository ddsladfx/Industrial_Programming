# Практическая работа 2

Каждый файл — отдельная программа на C++17 со своей функцией `main`. Объединять файлы в одну программу не нужно.

В методичке задания выполняются в Scratch. Здесь представлены консольные версии на C++ по запросу. Они не являются проектами `.sb3` и не заменяют графическую часть Scratch, если её требует преподаватель.

## Задание 1. Спортсмен

Файл: `task_1.cpp`.

Ввод: Ввод не нужен.

Консольная адаптация линейного алгоритма. Сообщение 1 передаётся по сценарию текстом; спрайтов, графики и воспроизведения звука здесь нет. Дополнительно добавлены разминка и завершение тренировки.

Пример результата:
```text
Текстовый сценарий тренировки и аплодисментов.
```

## Задание 2. Угадывание числа

Файл: `task_2.cpp`.

Ввод: Загадайте число от 1 до 1023. После каждой догадки введите <, > или =, сравнивая своё число с предложенным.

Бинарный поиск находит число не более чем за 10 догадок. Выводятся подсказки; некорректные и противоречивые ответы обрабатываются.

Пример ввода:
```text
=
```

Пример результата:
```text
Step 1: 512
Found: 512
```

Перед строками из примера программа также выводит правила ответа.

## Задание 3. Перевод в двоичную систему

Файл: `task_3.cpp`.

Ввод: Основание от 1 до 10 и запись неотрицательного числа без знака через пробел.

Сначала переводим в десятичную, затем делим на 2. Основание 1 означает унарную запись: 11111 = 5 = 101 в двоичной. Нуль задаётся как 0 при основании 2–10. Значение должно помещаться в unsigned long long; иначе Overflow.

Пример ввода:
```text
3 102
```

Пример результата:
```text
1011
```
