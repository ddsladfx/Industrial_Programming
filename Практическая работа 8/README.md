# Практическая работа 8

Каждый task_N.cpp — самостоятельная программа на C++17. Компилируйте один файл за раз.

## Задание 1. Быстрое возведение в степень

Файл: `task_1.cpp`.

Ввод: Основание a и целая степень n через пробел.

Функция использует двоичное возведение за O(log |n|). Отрицательные степени поддерживаются; 0^0 принято равным 1. Результат вещественный (long double), возможны округление и потеря очень малых значений; бесконечность обозначается Overflow.

Пример входных данных:
```text
10 12
```

Результат:
```text
1000000000000
```

## Задание 2. Рекурсивный НОД

Файл: `task_2.cpp`.

Ввод: Два натуральных a и b, не больше 10^9.

Рекурсивный алгоритм Евклида.

Пример входных данных:
```text
9 12
```

Результат:
```text
3
```

## Задание 3. Перекладывание ингредиентов

Файл: `task_3.cpp`.

Ввод: Неотрицательное целое n.

Ханойские башни: с первой салфетки на третью через вторую. Вывод содержит 2^n - 1 строк, поэтому практически используйте небольшие n.

Пример входных данных:
```text
2
```

Результат:
```text
Ingredient 1 move from 1 to 2
Ingredient 2 move from 1 to 3
Ingredient 1 move from 2 to 3
```
