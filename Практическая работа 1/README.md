# Практическая работа 1

Каждый файл — отдельная программа на C++17 со своей функцией `main`. Объединять файлы в одну программу не нужно.

## Задание 1. Обмен значений

Файл: `task_1.cpp`.

Ввод: Два целых числа a и b.

Обмен через сложение и вычитание без третьей переменной. Сумма a + b должна помещаться в long long.

Пример ввода:
```text
4 5
```

Пример результата:
```text
5 4
```

## Задание 2. Произведение факториалов

Файл: `task_2.cpp`.

Ввод: Неотрицательное целое n.

Факториал и произведение обновляются в одном цикле. Тип unsigned long long хранит точный ответ для n от 0 до 8. Для n >= 9 выводится Overflow, чтобы не выдавать неверное число.

Пример ввода:
```text
4
```

Пример результата:
```text
288
```

## Задание 3. Вычисление без условий

Файл: `task_3.cpp`.

Ввод: Число a: 0 или 1.

Формула b = 2 - a. Условных операторов нет.

Пример ввода:
```text
0
```

Пример результата:
```text
2
```

## Задание 4. Слияние массивов

Файл: `task_4.cpp`.

Ввод: Размеры n и m, затем n элементов первого и m элементов второго массива. Массивы отсортированы по возрастанию.

После ввода слияние выполняется за один цикл из n + m шагов; sort не используется.

Пример ввода:
```text
3 2
1 4 8
2 5
```

Пример результата:
```text
1 2 4 5 8
```

## Задание 5. Пропущенное число

Файл: `task_5.cpp`.

Ввод: Число n, затем n различных чисел из диапазона от 0 до n.

Из суммы чисел от 0 до n вычитаем элементы при вводе, за один цикл.

Пример ввода:
```text
4
0 1 4 2
```

Пример результата:
```text
3
```
