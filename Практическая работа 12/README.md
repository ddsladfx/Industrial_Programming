# Практическая работа 12

Каждый task_N.cpp — самостоятельная программа на C++17. Компилируйте один файл за раз.

## Задание 1. Сбор файлов в лабиринте

Файл: `task_1.cpp`.

Ввод: N M, затем N строк по M символов: 0, 1, P, E. Символы можно разделять пробелами.

В документе не указаны старт и правила перемещения. Принято: старт (0, 0), ход в четыре стороны, повторное посещение клеток разрешено; каждый P собирается один раз. Вход в E завершает маршрут. Обходим компоненту старта, не проходя через выход: все её файлы можно собрать с возвратами, затем выйти. Если выхода не достичь, ответ -1; если старт уже E, ответ 0. Без повторных посещений нужна другая постановка и другой алгоритм. Внутри исходного файла ошибочно указано занятие №11; номер папки взят из имени документа №12.

Пример входных данных:
```text
3 4
0P10
001P
P00E
```

Результат:
```text
2
```
