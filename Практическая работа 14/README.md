# Практическая работа 14

Каждый task_N.cpp — самостоятельная программа на C++17. Компилируйте один файл за раз.

## Задание 1. Проверка скобок

Файл: `task_1.cpp`.

Ввод: Одна строка длиной до 1000 символов.

Проверяются (), [] и {} с учётом вложенности, остальные символы игнорируются. Строка без скобок считается правильной. Ответ yes или no.

Пример входных данных:
```text
В МИРЭА и без меня?))
```

Результат:
```text
no
```

## Задание 2. Уникальные слова

Файл: `task_2.cpp`.

Ввод: Текст UTF-8 из русских и английских слов, до конца ввода.

Слова выводятся в порядке первого появления, как в примере документа. Регистр игнорируется, включая Ё/ё. Пунктуация разделяет слова; дефис между буквами сохраняется, потому что в примере «всё-таки» — одно слово. Цифры — разделители. Для UTF-8 использовано стандартное преобразование C++17; внешние библиотеки не нужны. В PowerShell завершите ввод Ctrl+Z и Enter либо передайте файл через cmd: task.exe < input.txt.

Пример входных данных:
```text
Кот, КОТ! Всё-таки кот.
```

Результат:
```text
кот
всё-таки
```

## Задание 3. Собственный стек с минимумом

Файл: `task_3.cpp`.

Ввод: Команды до конца ввода: push X, pop, min, empty.

Односвязный стек хранит в каждом узле минимум от него до дна. push, pop, empty и min работают за O(1), без готового std::stack. push ничего не выводит; pop выводит снятое число; min — минимум; empty — yes/no. pop/min для пустого стека выводят error. Формат команд добавлен для проверки, поскольку в документе он не задан.

Пример входных данных:
```text
push 5
push 2
min
pop
min
empty
```

Результат:
```text
2
2
5
no
```
