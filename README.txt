ЗАДАЧА 4 — АЛГОРИТМ В ВИДЕ МУЛЬТИКА В SCRATCH

ЗАПУСК
Открой Scratch → Файл → Загрузить с компьютера.
Выбери merge_visualization.sb3 и нажми зелёный флаг.
Для просмотра удобно включить полноэкранный режим сцены.
Зелёный флаг запускает мультик сначала. Красная кнопка останавливает.

ЧТО ПРОИСХОДИТ
Синие числа — массив A: -3, 1, 4, 4, 9.
Оранжевые числа — массив B: -2, 2, 4, 10.
Робот Слияша объясняет алгоритм репликами (без озвучки).
Два первых неиспользованных числа увеличиваются: сравниваем их.
Меньшее число подпрыгивает и перелетает в общий ряд.
При равенстве сначала выбирается число из A.
Когда A закончится, робот объяснит, почему берёт оставшееся число из B.
Счётчик показывает номер шага. Мультик длится около 45 секунд.
Итог: -3, -2, 1, 2, 4, 4, 4, 9, 10.

КАК УСТРОЕН ПРОЕКТ
Сцена → Код: настоящий алгоритм слияния, один «повторить (а + в)».
Перед каждым шагом увеличивается Сч. Поэтому это эквивалент
«Для Сч = 1 По а + в Цикл». Ровно один элемент добавляется за шаг.
Сцена выбирает персонажа по массиву и индексу и отправляет сообщение.
Код персонажей отвечает за увеличение и движение; циклов в нём нет.
Сообщения «передать ... и ждать» синхронизируют реплики и движение.
Результат также записывается в скрытый список «Результат».
В Scratch индексы с 1, в C++ с 0.

Это готовый постановочный пример: значения списков согласованы
с костюмами персонажей. Для другого набора чисел нужно изменить
и данные, и соответствующие костюмы, а для другой длины — также
персонажей, начальные а/в и их размещение.

C++
Открой merge.cpp в консольном проекте Visual Studio и запусти Ctrl+F5.
Обычные массивы, один for, четыре простые ветки if / else if / else.
Условие i == a означает, что A закончился. j == b — что B закончился.
i++ увеличивает i на 1, j++ увеличивает j на 1.
Массивы должны быть заранее упорядочены.
При изменении количества чисел обнови a и b.

ОБЪЯСНЕНИЕ ДЛЯ СДАЧИ
Первый неиспользованный элемент каждого массива — наименьший
в оставшейся части. Выбираем меньший из этих двух элементов
и сдвигаем только его индекс. Если один массив закончился,
берём из другого. На каждом шаге выдаётся ровно одно число,
поэтому все числа выводятся по возрастанию за а + в шагов.
Повторы сохраняются. Время O(а+в), дополнительная память в C++ O(1).
