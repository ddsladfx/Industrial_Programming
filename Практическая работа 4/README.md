# Практическая работа 4

Каждый файл — отдельная программа на C++17 со своей функцией `main`. Объединять файлы в одну программу не нужно.

## Задание 1. Калькулятор

Файл: `task_1.cpp`.

Ввод: Выражение A операция B. Целые A и B по модулю не больше 2147483647.

Операции +, -, *, /. Для деления выбран вещественный результат, поскольку вид деления в условии не уточнён. Деление на нуль обрабатывается.

Пример ввода:
```text
7 / 2
```

Пример результата:
```text
3.5
```

## Задание 2. Шоколадка

Файл: `task_2.cpp`.

Ввод: Положительные целые n, m и число долек k.

Нужен ровно один разлом: 0 < k < n * m, причём k делится на одну из сторон. Иначе NO. Площадь должна помещаться в long long.

Пример ввода:
```text
3 4 6
```

Пример результата:
```text
YES
```

## Задание 3. Римские числа

Файл: `task_3.cpp`.

Ввод: Целое X от 1 до 3999.

Использована обычная запись с IV, IX, XL, XC, CD, CM. За пределами диапазона выводится сообщение; обозначения для больших чисел в методичке не заданы.

Пример ввода:
```text
1994
```

Пример результата:
```text
MCMXCIV
```
